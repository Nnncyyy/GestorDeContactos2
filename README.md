# GestorDeContactos
Practica de Laboratorio: Desarrollo de un gestor de Contactos en C con GitHub y Microsoft Plannner

El objetivo es desarrollar un programa en lenguaje C que funcione como un gestor de contactos, utilizando GitHub para el control de versiones y Microsoft Planner para la gestión de tareas y colaboración en equipo

El gestor de contactos pretende realizar lo sigueinte:
    Agregar contactos nuevos (Datos)
    Mostrar
